# 名称评估：《入局》要不要换？

## 一、《入局》的底子（为什么它 initially 是对的）

1. **机制同构**：产品的核心动作就是"入局"——首页叫"入局点"、按钮叫"入局"、剧场叫"入局一戏"、法庭要"入局对赌"。名字和核心交互完全咬合，用户看到名字就能猜到玩法动词。
2. **动宾结构，有行动力**："入"是动作，"局"是场景，两个字把"你将走进一个故事现场"说完了。
3. **知乎语境亲和**：盐言故事读者对"局"字的戏剧联想（饭局、赌局、破局、设局）与短篇故事的强冲突气质一致。

## 二、它的三个真实短板

1. **搜索与传播的区分度低**："入局"是高频常用词，站内搜索会被无关内容淹没，社交口播时也不易唯一化（"诶你玩的那个叫啥？""入局""哪个入局？"）。
2. **题材联想偏窄**："局"自带商战/谍战/棋局的冷峻感，而书架里近半是甜宠、校园、治愈向内容——名字的"冷"和内容的"暖"有轻微错位。
3. **中英割裂**：仓库/部署名是 StoryDive（潜水意象），与"入局"没有字面对应，品牌资产是两套。

## 三、备选方案对比

| 候选 | 释义与优点 | 风险/代价 |
|---|---|---|
| **《入局》**（保留） | 机制同构、行动力强、所有界面文案零改动 | 搜索区分度低、题材偏冷 |
| **《入戏》** ⭐ 首选替代 | "入戏"兼容博弈感（入局）与情感代入（看戏看哭了），对甜宠治愈内容不违和；"戏"字直指互动叙事；"我们入个戏"口播自然 | 与"入局"同属高频词，区分度问题只解决一半 |
| **《盐灵游乐场》** | 直接贴赛道"跨次元游乐场"；"盐灵"（盐选之灵）是站内独有造词，**搜索零冲突**；剧场主持人 already 叫盐灵，品牌内自洽 | 五个字偏长；"盐灵"需要教育 |
| **《戏中局》** | "戏"与"局"双意象合一，文艺且有悬念感 | 三字偏书面，口播弱一些 |
| **《故事潜水》/《潜入》** | 与 StoryDive 对齐，中英统一 | 中文语感一般，"潜水"在中文互联网有"只看不发言"的负面歧义——恰好和产品相反 |
| **《执子入局》** | 棋局意象浓，仪式感强 | 四字文言，对下沉用户不友好 |

## 四、建议

**保留《入局》作为产品名，注册与传播时带副题**：

> **入局 · 知乎盐言故事互动剧场**
> （StoryDive — Play the scene）

理由：① 比赛评审语境下，"入局"与赛题"跨次元游乐场"的组合已经足够准确；② 机制同构的名字自带说明书属性；③ 距离提交时间近，改名会牵动 logo、域名（storydive-10wtw01.org 已上线）、站内 60+ 处文案，收益不抵成本。

**若赛后长期运营再考虑升级**：首选《入戏》（把"入局点"改叫"入戏点"代价很小），或直接起《盐灵游乐场》建立站内独占词。届时 StoryDive 可保留为英文名不动。

## 五、一句话总结

《入局》不是完美答案，但是当下**成本最低、机制最贴**的答案；真正的品牌升级留给赛后——用《入戏》或《盐灵游乐场》，把搜索区分度找回来。
